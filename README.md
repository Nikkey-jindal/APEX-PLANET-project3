# Advanced Styling and JavaScript – Task 3

This project was created as part of the **APEX Planet Internship – Task 3**.

The main objective of this task is to practice advanced CSS styling, responsive web design, JavaScript interactivity, and API integration.

## 🚀 Features

### 1. Responsive Design
- Responsive layout for desktop, tablet, and mobile devices.
- CSS Media Queries used to adjust layouts and font sizes.
- Mobile-friendly navigation and content sections.

### 2. Interactive JavaScript Quiz
- Multiple JavaScript-based questions.
- Multiple-choice options.
- Instant feedback for correct and incorrect answers.
- Automatic score calculation.
- Final score displayed after completing the quiz.

### 3. API Integration
- Fetches a random joke from a public API.
- Uses JavaScript `fetch()` and `async/await`.
- Dynamically displays API data on the webpage.
- Includes error handling when the API request fails.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Media Queries
- Fetch API
- Async/Await
- DOM Manipulation
